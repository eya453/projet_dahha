# Gestion des taches 
# Fonctionnalités:
 Ajouter une tâche
 Afficher toutes les tâches
 Rechercher une tâche par mot-clé
 Quitter le programme
 Ce projet permet d’organiser et de gérer les tâches quotidiennes à l’aide d’un programme Python exécuté dans la console
# Étapes réalisées
 création du fichier main.py
 développement des fonctionnalités principales
 test du programme dans VS Code
 initialisation du dépôt Git
 création des commits
 publication du projet sur GitHub
# Exécution du programme
ouvrir le dossier du projet dans VS Code
ouvrir le fichier main.py
cliquer sur Run Python File
utiliser le menu affiché dans le terminal
